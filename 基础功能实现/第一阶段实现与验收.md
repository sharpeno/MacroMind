# 第一阶段实现与验收记录

2026年10月7日。任务运行框架、只读工具接口和模型协议适配已实现，工程验证通过。真实模型服务联调尚未完成，因此此前约定的“实际调用模型”验收项仍待完成。当前成果不代表上线产品、方法语义验收或客户应用成效。

## 已交付

| 项目 | 实现及验收边界 |
|---|---|
| 任务运行框架 | 创建、状态、列表、同步运行、失败重试、中断恢复和同任务并发锁 |
| 固定版本输入 | 显式数据版本、方法版本、SHA256和日期；创建时复制快照，后续不跟随latest |
| 工具接口 | 文档目录、指定行读取、字面检索、引用校验、快照审计；仅访问本任务快照 |
| 模型接入 | Responses与Chat Completions适配器；密钥从环境变量读取；支持本机兼容端点 |
| 执行闭环 | 模型请求工具、程序执行工具、回传结果、接收结构化答案，错误引用可修正 |
| 运行与用量记录 | 每次尝试独立保存模型信息、工具调用、错误、耗时、服务报告的token和缺失用量 |
| 结果与审计 | JSON与Markdown结果，输入和产物哈希；全部结果待人工审阅 |

首期交互入口为命令行，没有增加网页、后台队列、多用户系统或自动材料入库。已有正式Validator和Audit Runner未改；新增审计检查任务快照与运行产物完整性，不冒称旧本体语义审计。

## 与并行审阅的边界

本轮新增runtime模块、专项测试、合成示例、使用说明及此验收目录；现有文件仅扩展CLI注册、README导航和.gitignore。本轮实现没有向正式材料、phase1、人工反馈接收、冻结方法或latest指针写入数据。只读导航检查也不触发材料重新导入或重复审阅。

以后运行任务时明确选择已封存的数据文件和方法文件，通过哈希固定。方法文件中的其他材料路径不会被自动展开；希望纳入的证据必须显式登记。另一边出现新版本时创建新任务；原任务的重试仍使用旧快照。
