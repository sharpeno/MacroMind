# 9527 方法规则 v0.1

2026-10-05。已冻结为本轮应用协议；不是已经验证的 Skill。规则由助手根据原话操作化，不假称全部为博主逐字表述。

## M01 用身份、承诺与失信代价约束动机推断

适用条件：存在明确行动主体、公开承诺和至少两种可选行动

需要输入：主体、职责与公开承诺；行动选项与代价；约束是否有证据

1. 列出全部可行选项，不能把排除一项当成另一项必然
2. 分别比较承诺、职位责任、执行成本及其他约束
3. 提出条件性基础判断，并列出相反路径

基础判断：有明确承诺时暂按其构成约束处理；不能据此认定一定兑现。

不适用/受限：若主体/承诺不可识别则不适用；材料不足以排除选项时保持多个分支。

更新规则：后续决定违背承诺或新约束出现，降低该约束权重；方向命中不证明动机。

原话依据：EP007/T02、EP007/T03、EP008/T01、EP001/C16、EP002/C14

## M02 拆开目标表态与可执行措施

适用条件：事件涉及政策目标、公开措施或预期改善

需要输入：目标与工具；宣布、实施、效果分别有哪些证据；观察范围和截止日

1. 把目标、宣布、安排、执行、效果分开记录
2. 检查措施的权限、对象、时限与传导环节
3. 在没有新改进证据时不提前计入改善收益，但保留未公开方案可能

基础判断：维持可观察的既有约束；未见措施时暂不计入措施收益，而非断言措施不存在。

不适用/受限：只有口号时可形成观察基线，但不能写成政策实施或效果；不强求未知内部计划。

更新规则：正式措施、可核验执行或实际效果出现时逐层升级；无效果或副作用证据可降低/撤回效果分支。

原话依据：EP007/T04、EP002/C12

## M03 检查数据结构、参照基准与反馈循环

适用条件：存在汇总数字、比较基准或政策与市场反馈信号

需要输入：数值原文、单位、时点、口径；分项或参照基准；信号产生过程

1. 分别检查分项、比较基准、循环反馈，不能混成单一理由
2. 有数字冲突就隔离相关计算，仍可分析其他定性内容
3. 主动保留广泛改善等替代解释，不先认定数据虚假

基础判断：只在已有口径内作判断；缺少分项时不从总量推得结构性改善。

不适用/受限：没有数据或反馈信号时不适用；分项缺失则对应子步骤未决，不编造数据。

更新规则：分项、修订、口径说明或独立信号出现时重评；反例可推翻原归因。

原话依据：EP007/T05、EP008/T03、EP001/C10

## M04 按条件追踪风险与叙事承接

适用条件：存在可明确表达的条件、传导路径和潜在承接方或效果

需要输入：触发条件；中间机制及约束；承接能力/效果证据

1. 逐环列出条件→机制→可能结果
2. 分别标注已知事实、间接推断和未证实假设
3. 保留条件不发生、传导受阻、承接不足的分支

基础判断：触发条件未确认时保留为情景，不视为结果已出现；仍可给出在当前约束下的基础判断。

不适用/受限：找不到可检验条件或机制时不输出确定预测；从AI转到别的领域须明确标为助手迁移。

更新规则：条件落地但传导未出现时降低判断；明确反向事实出现时撤回相关分支。

原话依据：EP007/T07、EP007/T08、EP008/T04、EP003/C16

## M05 形成判断，再用后来材料修正

适用条件：已有当时判断或本轮可以先封存初始判断

需要输入：当时可知的证据与方法版本；稳定判断编号；新增证据的发布时点

1. 先封存方法和初始判断，后加入新的观察
2. 逐项标记维持、理由补充、修改、撤回；不静默删掉错误
3. 区分博主忠实度、事实正确性、方法有效性三项检验

基础判断：没有新增观察就保留原判断和未决项，不伪造更新或命中。

不适用/受限：没有后续材料时仅完成初始登记；事后选例或已知结果不可作为盲测。

更新规则：任何新证据都与原判断逐项对照；定期复查需要单独启动，本轮不自动监控。

原话依据：EP007/T06、EP008/T06、EP008/T02
