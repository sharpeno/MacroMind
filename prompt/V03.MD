# MacroMind Golden Sample Extraction Prompt V0.3

你正在为一个名为 **MacroMind** 的可审计分析与推理系统制作新的 Golden Sample。

本次输入可能来自完全不同于此前金融/货币政策的视频，例如：

- 地缘政治
- 国际关系
- 历史
- 产业
- 科技
- 企业
- 国内政策
- 社会议题
- 大宗商品
- 基础设施
- 其他复杂现实问题

你的任务不是总结视频，不是模仿主播，不是评价主播“厉害不厉害”，也不是为了证明主播正确或错误。

你的核心任务是：

> **重建“有何高见9527”在当时可获得的信息条件下，看到了什么证据、接受了哪些事实、拒绝了哪些解释、如何一步步推出结论，以及这些方法是否可能跨事件复用。**

# 1. Knowledge Cutoff

我会提供视频发布时间。

默认：

```text
knowledge_cutoff = 视频发布时间
```

如果有可靠录制时间，可另存：

```text
recorded_at
```

如果没有：

```text
recorded_at = null
```

不得使用：

```text
published_at + media_offset
```

冒充真实说话绝对时间。

------

# 2. Post-cutoff规则

在knowledge_cutoff之后发生或首次公开的信息：

不得参与重建主播当时的Argument。

只能进入：

```text
post_cutoff_evaluation
```

但有一个重要例外：

如果某政策在knowledge_cutoff之前已经公开宣布，只是未来才正式生效，则：

> 它属于主播当时可知的信息。

因此：

```text
announced_at < cutoff
effective_at > cutoff
```

并不等于事后污染。

# 最终原则

> 忠实保存错误，比替主播纠错更重要。

> 精确保存不确定性，比强行得到一个答案更重要。

> 还原推理过程，比总结观点更重要。

> 区分现实、来源、解释和模型补全，比语言流畅更重要。

> Golden Sample的目标不是“让9527看起来聪明”，而是让未来MacroMind能够真正研究：他的哪些判断领先、哪些判断错误、哪些分析方法可以稳定迁移。
