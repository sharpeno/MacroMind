## 新案例与结果

选用[欧洲央行2025-06-05官方利率决定](https://www.ecb.europa.eu/press/pr/date/2025/html/ecb.mp250605~3b5f67d007.en.html)。其宣布调整关键利率，并说明后续不预先承诺固定路径。页面内容核对通过，保存短选段、定位与带归属记录；不保存完整历史网页。

先冻结v0.2，再读该发布。先前封存清单650个文件的精确日期/URL片段检查未命中；这只能证明该范围内未检出，不能证明助手从未知道该历史事件。初次rg因路径/权限不完整，最终改用已核验清单逐文件扫描。搜索结果显示了后期摘要，已披露，不称盲测。EP006不再作为留出样本。

基础判断：利率工具放松已宣布，可暂按融资约束边际缓和方向推演；实际传导、增长改善及连续降息仍需新证据。其他政策工具的方向单独保留。

案例包含4个参与者、5项方法应用和3条条件传导。公开目标与工具在材料给出的前提下部分匹配，不必采用隐藏目的解释；银行净收益、借款人与储户影响都保留为需分项验证的机制假说。没有由受益推断策划。

## 验证结果

- 原有695项测试通过，46.75秒；full_tests.*保存实际命令、stdout/stderr和退出码。
- 新应用正向检查及12类边界拒绝通过：受益推策划、缺失推不存在、确认隐藏动机、宣布推执行、措施推效果、遗漏方法、缺依赖、唯一动机、无条件链、无撤回、假引用、伪盲测。
- 冻结规则、案例及旧文件哈希一致；M03/M05未变。
- 本次3个脚本lint/format通过；只调整了本轮脚本导入与格式，日志保留。
- 页面12项交互检查通过，桌面/手机截图已目视检查；使用已有Edge/Playwright。证据见browser_evidence.json。

程序检查的是结构与标签边界，不具备识别所有自然语言错误的能力。单个由助手编写的案例通过这些检查，不证明系统已自动完成语义推理。
