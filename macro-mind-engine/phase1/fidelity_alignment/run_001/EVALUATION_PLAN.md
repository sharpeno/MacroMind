# 忠实度对照实验方案

先在472—475已曝光材料上诊断和调试，再对未曝光材料做固定配置检验。开发回放不证明未见迁移能力。历史模型知识与已知标题等泄漏仍需披露；不称严格历史盲测。

## 三组比较

A为普通分析提示；B为完整冻结v0.3；C为v0.3加本轮七项候选操作。三组使用相同模型、新闻包、问题、截止条件、历史状态、输出结构与长度预算。状态应一致，不能仅给C补材料。对后续效果有必要时，再单独比较C有无历史状态，不将其与规则增量混为一谈。

固定完整提示、模型标识和可记录配置；随机性不可控时披露并保留重复运行。三组使用相互独立的新会话，不带当前聊天的目标答案。手写答案不作为模型调用试验结果。本轮尚未执行这项实验。

## 开发阶段

1. 用已有12项诊断定位机制、排序和强度的缺口，核对每项是否在共同新闻输入内可见。
2. 如果目标推理依赖缺失材料，三组同时补入截止前来源，或将对应维度标NE。不能将目标字幕中的新事实只喂给C。
3. 制作目标侧判断单元，依OBJECTIVES.md评估；报告各维度变化、NE数量与错误案例，不只给总分。
4. 开发阶段修改候选后另存新版本。需区分框架表达改进、输入补足与执行改进，不能因为单例更像作者就宣布稳定特征。

## 固定配置的小批确认

建议首批两例使用既有顺序中的476、478，仅登记编号，本轮没有读取其内容。开始前重新确认仍未曝光。规则和状态截止策略一次冻结；允许按预定算法加入时间更早的信息，但不得将前例评阅反馈临时加入后例提示。所有待测答案封存后再统一开展目标侧对照，避免逐例反馈改变被测系统。

必须登记：模型、提示、规则、输入、历史状态、输出预算、选择顺序和评分规则。同日先后无法确认或材料缺失的单元标NE，不以推测填齐。

候选进入下一轮扩样的预设条件：相对B，在每个案例的推理/排序/倾向三个核心维度均无下降，至少一个核心维度提升；无新增伪造归属或机制、无信息泄漏；若核心维度NE无法比较，则本批为证据不足。该条件只是进入扩样的门槛，两例不能认证方法有效。没有满足时保留失败记录，回开发材料修订，不在已曝光例上重跑后宣称首次通过。

人工纠正成本记录修改的核心判断单元数量，计时可选；不以更长答案、更多规则引用或工程检查数代替忠实度。事实/预测评价单独保存，暂不作为本批通过门槛。
