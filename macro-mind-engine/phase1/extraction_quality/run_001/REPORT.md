# 提取质量约束与回归检查：工程结果

已完成本轮授权的质量约束和回归检查工作。当前系统仍是助手注释加编译器，不是自动语义提取器。新增的质量门禁位于编译之前，不能替代对新材料的语义审核。

## 实际新增能力

- 固定政策文件及其SHA256，核对原字幕指纹、证据cue、引用和编号。
- 检查已审前提、范围、立场和历史比较结构的关键措辞；措辞变化需重新核对。
- 强制局部理由只连接经审核的目标；例如短债融资压力不能连向整套化债方法。
- 保留背景展望但禁止重新加入具体预测候选；预测分类列表的任何改变也会触发复核。
- 用户已决定只作上下文的段落，不自动新增主张。
- 已审表述新增、改变、删除时需要复核，包括“保留关键词但追加未证实结论”的情况。
- 下拉选择忠实但附带文字意见时，先检查文字，不自动结束处理。

新的受控入口为scripts/compile_reviewed_episode.py。返回0表示既定门禁检查通过；1表示新变化待复核；2表示错误阻断。仅返回0时才允许在全新目录执行编译。结构可编译不等于内容被人工认可。

## 尚不能得出的结论

这些是定向的保留性与防回退检查。词语出现不证明语义正确，配置中的旧基线也可能含未发现问题。unreviewed_ids是保守提示而非完整历史审核台账；没有因指纹一致把所有内容标为已审。

未审C07案例只验证“新表述进入复核”的路由，不是留出集准确率测量。对任何人的素材提炼出可靠框架、用新新闻分析、预测效果评估及完整可视化仍未实现；本轮为这些目标提供数据质量约束。

原53项非引用未决信息、投行历史版本及引用时序、时长差异继续保留。未批准全库、扩样或生成Skill。
