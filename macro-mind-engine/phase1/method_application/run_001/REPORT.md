## 形成的分析

基础判断 J01：在本篇报道覆盖范围内，暂按能源供应扰动风险尚未消解继续分析；不提前计入未证实的新增设施损失，也不提前计入尚未落实的缓和收益。

未知事实 J02：特定设施是否遭袭、受损多少尚未由本包证实。缺证据不能推出未发生；但这不阻止J01作为可撤回的工作基线。

三个后续分支：实际升级且替代不足；外交安排落实后缓和；即使冲突持续，贸易或供给适应也可能弱化冲击。每一项都必须观察执行或实际运行，不能只由表态和价格变动直接确认。
