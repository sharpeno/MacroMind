# 方法v0.2与新材料应用

已将P01/P02/P03落实到M01/M02/M04；M03/M05保留原规则。v0.1和首轮答案不改。冻结规则在新案例读取前完成。

## 方法规则

### M01 分析多方利益、执行依赖与行动约束

输入：主体、职责与公开承诺；行动选项与代价；约束是否有证据；参与者：决策者、执行方、合作方、受影响方；逐方收益、成本与依赖，未知字段显式保留

1. 列出全部可行选项，不能把排除一项当成另一项必然
2. 分别比较承诺、职位责任、执行成本及其他约束
3. 提出条件性基础判断，并列出相反路径
4. 建立参与者关系表：谁需要谁配合，谁付成本，谁可能反对；每条关系绑定证据或标为假说。
5. 从职位、行为和约束比较可行解释；以区别性证据支持排序，不以“谁受益”直接指认动机。

基础判断：有明确承诺时暂按其构成约束处理；不能据此认定一定兑现。

边界：若主体/承诺不可识别则不适用；材料不足以排除选项时保持多个分支。

更新：后续决定违背承诺或新约束出现，降低该约束权重；方向命中不证明动机。

### M02 检验目标与手段是否匹配，再比较动机解释

输入：目标与工具；宣布、实施、效果分别有哪些证据；观察范围和截止日；公开目标、实际措施和实现目标所需条件；可观察的行为变化与执行时点

1. 把目标、宣布、安排、执行、效果分开记录
2. 检查措施的权限、对象、时限与传导环节
3. 在没有新改进证据时不提前计入改善收益，但保留未公开方案可能
4. 判断手段与目标匹配、部分匹配、不匹配或未知；明确缺少的是能力、执行、时间还是信息。
5. 出现不匹配时至少保留能力不足、执行迟滞、公开信息不全等解释；隐藏目的只能作为候选，提出可区分证据。
6. 手段匹配时不强行寻找隐藏目的；也不把匹配写成效果已经实现。

基础判断：维持可观察的既有约束；未见措施时暂不计入措施收益，而非断言措施不存在。

边界：只有口号时可形成观察基线，但不能写成政策实施或效果；不强求未知内部计划。

更新：正式措施、可核验执行或实际效果出现时逐层升级；无效果或副作用证据可降低/撤回效果分支。

### M03 检查数据结构、参照基准与反馈循环

输入：数值原文、单位、时点、口径；分项或参照基准；信号产生过程

1. 分别检查分项、比较基准、循环反馈，不能混成单一理由
2. 有数字冲突就隔离相关计算，仍可分析其他定性内容
3. 主动保留广泛改善等替代解释，不先认定数据虚假

基础判断：只在已有口径内作判断；缺少分项时不从总量推得结构性改善。

边界：没有数据或反馈信号时不适用；分项缺失则对应子步骤未决，不编造数据。

更新：分项、修订、口径说明或独立信号出现时重评；反例可推翻原归因。

### M04 追踪条件传导、利益变化与内外反馈

输入：触发条件；中间机制及约束；承接能力/效果证据；传导中间环节、受益者和成本承担者；参与者可能响应以及反向反馈

1. 逐环列出条件→机制→可能结果
2. 分别标注已知事实、间接推断和未证实假设
3. 保留条件不发生、传导受阻、承接不足的分支
4. 按条件→行为/资源变化→结果→参与者响应建立链条，逐环标证据与缺口。
5. 列出可能受益和受损者，但禁止由受益跳到策划或责任归属。
6. 保留至少一个阻断或反向反馈；缺少中间证据时保留条件性基础判断，不造出确定结果。

基础判断：触发条件未确认时保留为情景，不视为结果已出现；仍可给出在当前约束下的基础判断。

边界：找不到可检验条件或机制时不输出确定预测；从AI转到别的领域须明确标为助手迁移。

更新：条件落地但传导未出现时降低判断；明确反向事实出现时撤回相关分支。

### M05 形成判断，再用后来材料修正

输入：当时可知的证据与方法版本；稳定判断编号；新增证据的发布时点

1. 先封存方法和初始判断，后加入新的观察
2. 逐项标记维持、理由补充、修改、撤回；不静默删掉错误
3. 区分博主忠实度、事实正确性、方法有效性三项检验

基础判断：没有新增观察就保留原判断和未决项，不伪造更新或命中。

边界：没有后续材料时仅完成初始登记；事后选例或已知结果不可作为盲测。

更新：任何新证据都与原判断逐项对照；定期复查需要单独启动，本轮不自动监控。
