美财长耶伦：美国有能力同时为以色列和乌克兰提供军事支持
原创
环球市场情报
2023-10-16 22:39 星期一
财联社 夏军雄
责编 杨永武
①美国财政部长耶伦表示，美国绝对有能力同时为乌克兰和以色列提供军事支持；
②耶伦周一在接受媒体采访时称，美国经济和公共财政状况良好，能够确保美国在海外的利益得到支持。

财联社10月16日讯（编辑 夏军雄）当地时间周一（10月16日），美国财政部长耶伦表示，美国绝对有能力同时为乌克兰和以色列提供军事支持。

耶伦周一在接受媒体采访时称，美国经济和公共财政状况良好，能够确保美国在海外的利益得到支持。

当被问及美国是否有能力同时向以色列和乌克兰提供军事支持时，耶伦回答称：“答案是绝对的。”

耶伦表示：“美国当然有能力与以色列站在一起，支持以色列的军事需要，我们也能够而且必须支持乌克兰与俄罗斯的斗争。”

美国总统拜登近日在接受媒体采访时也表示，美国将向以色列提供他们需要的一切。

耶伦呼吁共和党人尽快选出新的众议院议长，以便通过更多的财政支持。

自麦卡锡下台以来，美国众议院一直处于不确定状态，议长位置空缺导致众议院的许多工作陷入停顿。

耶伦说：“我们确实需要为以色列和乌克兰筹集资金，这是当务之急。这真的取决于众议院寻找并安排一位议长，从而让我们可以通过立法。”

本轮巴以冲突爆发已经一周有余，目前局势仍有升级的态势。冲突导致石油和天然气价格出现波动，而能源价格飙升是去年导致全球通胀高企的重要因素。

耶伦认为，现在就判断巴以冲突的经济影响还为时过早。

当被问及美国财政部是否还能采取更多措施向伊朗施压，让其不要卷入战争时，耶伦回答说：“我知道正在进行外交对话，但我不打算详细介绍它们。”

据俄罗斯卫星通讯社15日报道，被问及在以色列将要在加沙开始地面行动时伊朗是否准备进行干预以及在这种情况下可能采取什么措施的问题时，伊朗驻联合国特使表示，“在以色列政府不敢袭击伊朗、打击伊朗的利益和公民的情况下，伊朗武装力量不会参与。巴勒斯坦抵抗阵线可以自己保护自己。”
