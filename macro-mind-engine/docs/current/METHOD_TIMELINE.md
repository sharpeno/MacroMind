程序拒绝在早期快照中使用未来公开材料，要求与前一快照的指纹连接，保留每个判断ID并禁止覆盖旧输出。执行证据与广泛效果证据分开。判断本身由助手编写；程序记录与检查，不自动读新闻做语义推理。

重要限制：这次作者已经看过后续结果，属于历史回看，不是盲测或当时预测。过宽的融资成本分支用于检验撤回机制，不是9527观点，也不是模型真实事前错误。方法本身在2026年才整理，不据此计算2024年的预测成绩。

## 操作入口

在工程目录运行：

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe scripts/run_method_timeline.py --packet phase1/method_timeline/run_001/T1.input.json --previous phase1/method_timeline/run_001/T0/snapshot.json --output phase1/method_timeline/example_replay
```

这是重放示例；输出目录必须不存在。新增时点需要新输入、较晚截止日期和前一结果的object_hash。来源内容发生修订应使用新ID；每个判断保留相同ID以便追踪，不能静默删除错误分支。

来源保存的是核实过的短选段与助手摘要、官方链接及定位，不是完整网页或历史版本档案。材料发布日与事件日分开，按日截止，未模拟日内交易级信息集。

下一步可先做未看答案的留出案例，或引入第二套方法；本轮未自动启动。当前原始资料、run_005与已认可的方法原型都保留。
